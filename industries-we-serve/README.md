# Industries We Serve

Copy these three files into the other project:

1. Add `industries-we-serve.html` where the section should appear.
2. Load `industries-we-serve.css` from the page `<head>`.
3. Load `industries-we-serve.js` before `</body>` because it activates the scroll reveal. If you do not want the animation, remove the `data-reveal` attributes from the six `<article>` elements.

The section is framework-independent and has no image dependency. The CSS uses Arial as a safe fallback; change the font declarations if the new project uses a different typeface.
